CrossADFS 0.9.25 - types for newly copied files

The associations below set the Acorn catalogue type. They do not convert
file contents or install a viewer/player. The A3010 still needs suitable
software to open each format. All extension matching ignores letter case.

Existing Acorn metadata carried in the CrossADFS1 file comment takes
priority when restored. This list applies to new files without that
record. Unknown names remain Data (&FFD).

IMPORTANT DETAILS
IFF is a container. FORM ILBM and PBM are pictures; AIFF/AIFC are audio.
Other IFF subtypes, including 8SVX and ANIM, remain Data in this build.
The program identifies the type, not whether a complete file is valid.
Use .iff or .img with suitable headers; a disk image named .img is not
automatically labelled as a GEM picture. Type detection uses only bytes
already being copied and does not add floppy reads. Non-sequential writes
fall back to the filename association; existing update handles retain the
old Acorn type. CRLF detection changes the type, not the line endings.

ZIP has historical DDC and modern A91 associations. This build keeps the
existing A91 mapping from the RISC OS MimeMap; old archive applications
may need DDC instead. Similarly, AU and tracker associations vary between
players. Original Acorn catalogue metadata is preserved when available.

.INFO ICONS
CrossADFS-generated application icons contain ACORN_TYPE, ACORN_LOAD and
ACORN_EXEC ToolTypes. These can be inspected using Icon Information.
Ordinary icons may contain only a generic Project/Tool/Drawer kind and a
Default Tool; that is not a universal content-type identifier. This build
does not import arbitrary .info ToolTypes as catalogue metadata. File
comments remain the automatic metadata carrier described in METADATA.txt.

Ogg/FLAC and other formats without a verified association in this change
remain Data when new. An existing type in a returned metadata record is
still restored. None of these associations guarantee A3010 playback.

TEST THIS BUILD
Install and restart. Copy a new PDF, IFF/ILBM picture, tracker file and one
of the added extensions from the Amiga hard disk onto your Acorn test
disk. Use files without a CrossADFS1 comment for the new-file defaults.
On the A3010 check the catalogue type and open with a suitable application.
The metadata round trip reported working in 0.9.24 is retained; a copy
carrying its old comment should keep its original type instead.
